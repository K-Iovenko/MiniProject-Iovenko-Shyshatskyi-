## Ідея, акція, аналіз
Palantir Technologies (PLTR) - американська компанія, що розробляє програмне забезпечення для аналізу великих масивів даних. Їх головними клієнтами є держустанови, спецслужби та військові організації.

Ця компанія була обрана завдяки стрімкому зростанню її капіталізації (після 2022 р.), а також через високу волатильність за досліджуваний період (червень 2025 - червень 2026). Ціна акції коливалась у діапазоні зі 105 доларів до 201 долара. Таке коливання створює ідеальні умови для тестування методики "Moving Average Crossover", для зображення її зручностей та недоліків. Це означає, що часта зміна ціни дозволить бачити більше перетинів двох ковзних і відповідно частіші сигнали купівлі та продажу.
## Опис процесу аналізу
* Джерело даних: yfinance (Yahoo Finance API)
* Період: 2025-06-01 - 2026-07-21 
* Бібліотеки: pandas (обробка даних), matplotlib (візуалізація)
* Стратегія: Moving Average Crossover (SMA 20 / SMA 50)
* Логіка сигналів: Golden Cross (buy) / Death Cross (sell)
